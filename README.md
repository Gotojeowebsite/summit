# summit

A small Codespaces-friendly launcher for the Summit K12 login page.

## Run locally or in GitHub Codespaces

1. Open the repository in Codespaces.
2. Start the app:
   ```bash
   npm install
   npm start
   ```
3. Open the forwarded port `3000` in your browser.
4. Use the UI to launch Summit K12 login.

## Notes

- The app does not store your Summit credentials.
- Login is handled directly on Summit K12 pages after you launch the login flow.
