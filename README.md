# summit

This repository does **not** provide or support bots that:

- log into third-party school accounts,
- auto-complete PLPs/coursework,
- bypass intended learning workflows, or
- generate answers to submit on a student's behalf.

If you want help building something legitimate, a safe alternative is a
**study helper** (timers, note-taking, progress tracking, and reminders) that
assists learning without automating graded work submissions.
